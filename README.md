
# OSINT-Projekt

## Ziel
Analyse öffentlich zugänglicher Unternehmensinformationen
mit Python.

## Technologien
- Python
- Requests
- BeautifulSoup
- Git und GitHub

## Projektstruktur
- `src/harvester.py` – Webseiten auslesen
- `src/social_search.py` – Informationen durchsuchen
- `src/relationship_mapper.py` – Beziehungen modellieren
- `src/graph_visualizer.py` – Beziehungen visualisieren

## Installation
```bash
python -m pip install -r requirements.txt
```

## Ausführung
```bash
python src/harvester.py
```
